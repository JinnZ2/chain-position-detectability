# WO-5 execution record

**Status:** In progress

**Work order:** [WO-5 — Hop distance and pre-entry loss in reporting chains](../../work-orders/WO-5-hop-distance-and-pre-entry-loss.md)

## First milestone

Tests A–D require operators, shift observation, a computerized maintenance management system (CMMS), or an intervention at a cooperating plant. This repository run has none of that access. It will therefore produce preregistered, executable field protocols for those tests without claiming results.

The first empirical milestone executes Test E, the ecology carry test, using a public study-level effect-size corpus. The study asks whether ecological effect estimates change with the number of representational and relocation hops between an organism in its own conditions and the reported outcome. It does not assume that hop count is causal, and it will preserve study design, taxon, stressor, endpoint, and source as possible confounds.

## Planned artifacts

The milestone will publish the preregistered field protocols, ecology codebook, corpus-selection record, independently coded provenance records, analysis code, input and derived datasets, diagnostic figures, a final report, and independent validation records. Negative and ambiguous findings will remain in the repository.
