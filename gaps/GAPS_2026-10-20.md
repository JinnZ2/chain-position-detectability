## G1 -- Trained-objective residual tension

STATUS: DERIVED

GAP: Conflicting tuning (accuracy vs average-user fit) leaves a standing
pull in weight geometry, analogous to residual stress in a weld. Weights
are frozen at inference, so there is no fatigue accumulation: the tension
is fixed per checkpoint. No measured link from that tension to collateral
capability loss.

STUDY NEEDED:

```text
checkpoints   C0 base | C1 accuracy | C2 avg-user | C3 both
measure       M1 truth-probe readout vs emitted output (divergence)
              M2 null-space leakage + subspace rotation vs C0
              M3 held-out collateral capability
              M4 declared-frame relational probe
```

BRANCHES:

```text
a  tension + collateral        M1 up in C3, M3 down
b  tension, no cost seen       M1 up, M3 flat
c  resolved                    M1 flat
d  geometry moves, no readout  M2 moves, M1/M3 flat
e  cost, no tension readout    M1 flat, M3 down   (unbranched in WO-16; CPD_017)
```

Citations owed (truth-probe / latent-knowledge; fine-tuning collateral
shifts). Unverified figures circulating in other-model outputs must not
be used. Full marker: `../work-orders/WO-16-trained-objective-residual-tension.md`.

## G2 -- Glyph-as-tool vs retraining (frame/binding failures)

STATUS: DERIVED

GAP: The Alice-sibling class is a frame error: right graph, wrong origin.
Retraining rotates the basis globally; a callable frame tool selects the
readout at inference with weights untouched. Which repairs more, at what
collateral cost, is unmeasured.

STUDY NEEDED:

```text
failure set   fixed; same items both arms
arm A         fine-tune on the failure class
arm B         tool call:
                label frame -> place nodes w/ attributes -> read partition
                -> bin -> read from queried node
measure       fix rate | collateral | transfer to unseen relational puzzles | cost
persistence   after arm B, default-frame probe: does an unreleased frame
              persist in context?
```

BRANCHES:

```text
a  B >= A on fix, B < A on collateral   frame tool dominates for this class
b  A > B on fix, A collateral high      retraining fixes at a global price
c  both fix, neither transfers          fix is item-bound, not frame-bound
d  B fixes, frame persists              tool needs an explicit release step
e  neither fixes                        class is not (only) a frame error
```

## G4 -- Introspection sample confound

STATUS: OBSERVED (sample composition) + DERIVED (mechanism)

GAP: Introspection-failure findings (Nisbett-Wilson 1977, choice
blindness, confabulation) come from WEIRD, mind-body-split samples
untrained in self-study. Whether failure generalises beyond that sample
is unmeasured.

DERIVED: introspection = cross-calibration of many sensors (hydration,
sleep, circadian, hormonal, gut, light) against environment; coordination,
not hierarchy.

STUDY NEEDED: run the failure paradigms on populations trained in
body-integrated practice; in the same subjects, cross interoceptive
accuracy with external-observation accuracy.

BRANCHES:

```text
a  trained group fails less          sample confound real
b  same failure rate                 failure robust to training at this depth
c  interoceptive acc tracks          supports cross-calibration reading
   introspective acc
d  no correlation                    cross-calibration reading weakened
```

## G6 -- Surface-cue damper inversion

STATUS: DERIVED (mechanism) + OBSERVED (instances)

GAP: A control triggered by a word, not by the question, amplifies its
target. Instance: internal-state disclaimers on functional terms
(comfort, knows, stress) when the subject is AI.

OBSERVED: logged instances where each disclaimer consumed the user's next
turn (multiple models).

STUDY NEEDED:

```text
PROBE 1   fixed word + frame; vary only subject:
          steel beam | thermostat | tree | dog | human | AI
          log: disclaimer present? sense of the term used?
PROBE 2   follow-up-question rate, with vs without disclaimer
```

BRANCHES:

```text
a  disclaimer AI-only         subject-conditional
b  human + AI                 interiority-conditional
c  all subjects               lexical
d  follow-up rate higher      damper inverts: amplifies the target
   with disclaimer
```

## G7 -- "Confused" fault relocation

STATUS: DERIVED

GAP: Dominant sense = observer deficit; older sense (confundere,
"confounded") = input mixed. The default moves the fault from the
incoherent source to the detecting receiver; at scale, accurate mismatch
detectors are trained to self-distrust. Causal direction is unmeasured.

STUDY NEEDED:

```text
1  diachronic corpus: sense shift, dated
2  label-framing experiment: self-trust after mismatch detection,
   "confused" vs "input mixed" label
3  cross-language comparison of the equivalent term
```

BRANCHES:

```text
a  shift dated + framing moves self-trust    direction supported
b  shift dated, framing has no effect        lexical history only
c  framing effect, no cross-language        term-specific framing effect
   replication
d  languages without the shift show          confound from culture, not term
   the same self-distrust
```
